# 머신러닝 기초

## [ML-01] 머신러닝이란
**머신러닝**은 규칙을 사람이 직접 코딩하지 않고 데이터에서 패턴을 학습해 예측하는 기술입니다. 학습 방식에 따라 **지도학습**, **비지도학습**, **강화학습**으로 나눕니다.

## [ML-02] 지도학습과 회귀, 분류
**지도학습**은 정답(라벨)이 있는 데이터로 학습하는 방식입니다. 정답이 연속적인 숫자이면 **회귀**, 정답이 스팸과 정상 같은 범주이면 **분류** 문제입니다. 집값 예측은 회귀, 스팸 메일 판별은 분류의 예입니다.

## [ML-03] 비지도학습
**비지도학습**은 정답 없이 데이터의 구조를 찾는 방식입니다. 비슷한 데이터끼리 묶는 **군집화**의 대표 알고리즘이 K-평균입니다. 변수의 수를 줄이는 **차원 축소**도 비지도학습에 속합니다.

## [ML-04] 과대적합과 과소적합
모델이 학습 데이터에는 매우 잘 맞지만 새 데이터에서 성능이 떨어지는 현상을 **과대적합**이라고 합니다. 반대로 학습 데이터조차 제대로 맞추지 못하는 상태는 **과소적합**입니다. 과대적합은 데이터 늘리기, 모델 단순화, **규제** 등으로 줄입니다.

## [ML-05] 분류 평가지표
분류 모델의 **정확도**는 전체 중 맞힌 비율입니다. **정밀도**는 양성이라고 예측한 것 중 실제 양성의 비율이고, **재현율**은 실제 양성 중 모델이 찾아낸 비율입니다. 정밀도와 재현율의 조화평균이 **F1 점수**입니다. 정상이 99퍼센트인 불균형 데이터에서는 정확도만 보면 속기 쉽습니다.

## [ML-06] 교차검증
**교차검증**은 데이터를 여러 묶음으로 나눠 번갈아 검증용으로 쓰면서 성능을 평균내는 방법입니다. 데이터가 적을 때도 성능을 안정적으로 추정할 수 있고, 가장 흔한 방식은 **K-겹 교차검증**입니다.

## [ML-07] 경사하강법
**경사하강법**은 손실 함수의 기울기를 따라 파라미터를 조금씩 갱신하며 손실이 작아지는 방향으로 가는 최적화 방법입니다. 한 번에 얼마나 움직일지 정하는 값이 **학습률**이며, 너무 크면 발산하고 너무 작으면 학습이 느립니다. 모델의 예측과 정답의 차이를 수치로 나타낸 것이 **손실 함수**입니다.

## [ML-08] 의사결정나무와 랜덤 포레스트
**의사결정나무**는 질문을 이어 가며 데이터를 나누는 트리 구조의 모델로, 결과를 사람이 읽고 설명하기 쉽습니다. 나무를 너무 깊게 키우면 과대적합되기 쉽습니다. 여러 나무를 모아 투표하는 방식이 **랜덤 포레스트**입니다.
