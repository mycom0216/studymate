# 데이터 처리와 분석

## [DA-01] 넘파이와 판다스
**NumPy**는 다차원 배열을 빠르게 계산하게 해 주는 라이브러리입니다. **pandas**는 표 형태의 데이터를 다루는 라이브러리이며, 표 하나를 **DataFrame**이라고 부르고 열 하나는 Series라고 부릅니다. CSV 파일은 read_csv 함수로 불러옵니다.

## [DA-02] 결측치 처리
값이 비어 있는 데이터를 **결측치**라고 하며, pandas에서는 isnull로 찾습니다. 결측치는 해당 행을 지우거나 평균, 중앙값 같은 대푯값으로 채워서 처리합니다. 이상치가 많은 데이터는 평균보다 **중앙값**으로 채우는 편이 안전합니다.

## [DA-03] 이상치
다른 값들과 동떨어진 값을 **이상치**라고 하며 모델 성능을 떨어뜨릴 수 있습니다. 사분위수 범위의 1.5배를 벗어나는 값을 이상치로 보는 **IQR** 방법이 널리 쓰입니다. 이상치는 제거하거나 상한과 하한 값으로 바꿉니다.

## [DA-04] 정규화와 표준화
특성마다 값의 범위가 다르면 학습이 불안정해지므로 **스케일링**을 합니다. **정규화**는 값을 0과 1 사이로 맞추는 방법이고, **표준화**는 평균을 0, 표준편차를 1로 맞추는 방법입니다. 범주형 데이터는 **원-핫 인코딩**으로 숫자 벡터로 바꿉니다.

## [DA-05] 학습 데이터와 테스트 데이터
모델이 새 데이터에서도 잘 맞는지 확인하려고 데이터를 **학습 데이터**와 **테스트 데이터**로 나눕니다. 보통 8대 2 또는 7대 3 비율을 쓰며 scikit-learn의 train_test_split으로 나눕니다. 테스트 데이터를 학습에 쓰면 성능이 부풀려지는 **데이터 누수**가 생깁니다.

## [DA-06] 데이터 시각화
데이터의 분포와 관계는 그래프로 확인하면 이해하기 쉽습니다. **matplotlib**은 가장 기본적인 파이썬 시각화 라이브러리이고 **seaborn**은 통계 그래프를 더 간단히 그리게 해 줍니다. 값의 분포는 **히스토그램**, 두 변수의 관계는 산점도로 나타냅니다.
