# 웹, 데이터베이스, IoT

## [WB-01] HTTP와 상태 코드
**HTTP**는 웹 브라우저와 서버가 요청과 응답을 주고받는 규칙입니다. 데이터를 조회할 때는 **GET**, 새로 만들 때는 **POST**, 수정은 PUT, 삭제는 DELETE 메서드를 씁니다. 응답 상태 코드 200은 성공, **404**는 찾을 수 없음, 500은 서버 오류를 뜻합니다.

## [WB-02] REST API와 JSON
**REST API**는 주소로 자원을 나타내고 HTTP 메서드로 동작을 표현하는 설계 방식입니다. 서버와 클라이언트가 데이터를 주고받을 때는 키와 값으로 이루어진 텍스트 형식인 **JSON**을 가장 많이 씁니다.

## [WB-03] 프런트엔드와 백엔드
화면을 구성하는 부분을 **프런트엔드**, 데이터 처리와 저장을 맡는 서버 쪽을 **백엔드**라고 합니다. 프런트엔드는 HTML로 구조를, **CSS**로 모양을, **JavaScript**로 동작을 만듭니다.

## [WB-04] SQL 기본
**SQL**은 관계형 데이터베이스를 다루는 언어입니다. 데이터를 조회하는 **SELECT**, 추가하는 INSERT, 수정하는 UPDATE, 삭제하는 DELETE가 기본 명령입니다. 표에서 각 행을 고유하게 구분하는 열을 **기본키**라고 하고, 다른 표의 기본키를 참조하는 열은 **외래키**입니다.

## [WB-05] SQLite와 서버형 데이터베이스
**SQLite**는 서버 없이 파일 하나로 동작하는 가벼운 데이터베이스로 소규모 앱과 학습용으로 알맞습니다. 사용자와 데이터가 많아지면 MySQL이나 PostgreSQL처럼 별도 서버가 있는 데이터베이스를 씁니다.

## [WB-06] 아두이노
**아두이노**는 센서와 부품을 연결해 동작을 제어하는 오픈소스 마이크로컨트롤러 보드입니다. 프로그램은 처음 한 번 실행되는 **setup** 함수와 계속 반복되는 **loop** 함수로 구성됩니다. 온도나 조도 같은 아날로그 센서 값은 analogRead로 읽습니다.

## [WB-07] IoT와 센서 데이터 연동
**IoT**는 사물에 센서와 통신 기능을 달아 데이터를 주고받게 하는 기술입니다. 센서 값을 서버로 보낼 때는 시리얼 통신이나 Wi-Fi를 거쳐 HTTP 또는 **MQTT** 같은 가벼운 메시지 프로토콜을 사용합니다. 쌓인 센서 데이터를 AI로 분석하면 이상 징후 감지에 활용할 수 있습니다.
