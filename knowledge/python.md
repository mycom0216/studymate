# 파이썬 기초

## [PY-01] 변수와 자료형
파이썬에서 **변수**는 값을 가리키는 이름으로, 별도의 타입 선언 없이 값을 대입하면 만들어집니다. 기본 자료형에는 정수 **int**, 실수 **float**, 문자열 **str**, 참과 거짓을 나타내는 **bool**이 있습니다. 파이썬은 실행 중에 자료형이 결정되는 **동적 타이핑** 언어입니다.

## [PY-02] 리스트와 튜플
**리스트**는 대괄호로 만드는, 순서가 있고 내용을 바꿀 수 있는 자료구조이며 append로 요소를 추가합니다. **튜플**은 소괄호로 만들고 한 번 만들면 요소를 바꿀 수 없습니다. 인덱스는 0부터 시작하고 -1은 마지막 요소를 가리킵니다.

## [PY-03] 딕셔너리와 집합
**딕셔너리**는 키와 값을 쌍으로 저장하는 자료구조이며 중괄호로 만듭니다. 키로 값을 찾기 때문에 조회가 빠르고 키는 중복될 수 없습니다. **집합**은 중복을 허용하지 않는 요소의 모음이며 순서가 없습니다.

## [PY-04] 조건문과 반복문
**조건문**은 if, elif, else로 조건에 따라 실행할 코드를 고릅니다. 같은 작업을 되풀이할 때는 **반복문**을 쓰며, for는 요소를 하나씩 꺼내고 while은 조건이 참인 동안 계속 실행합니다. 반복을 중간에 끝내려면 **break**, 이번 차례만 건너뛰려면 **continue**를 사용합니다.

## [PY-05] 함수
**함수**는 def 키워드로 정의하며 반복되는 코드를 묶어 재사용하게 해 줍니다. 함수가 값을 돌려줄 때는 **return**을 사용하고, 함수가 입력으로 받는 변수를 **매개변수**라고 부릅니다. 매개변수에 기본값을 지정하면 호출할 때 인자를 생략할 수 있습니다.

## [PY-06] 예외 처리
실행 중 오류가 나도 프로그램이 멈추지 않게 하려면 **try-except** 구문으로 예외를 처리합니다. 예외 발생 여부와 관계없이 항상 실행할 코드는 **finally** 블록에 둡니다. 0으로 나누면 **ZeroDivisionError**가 발생합니다.

## [PY-07] 모듈과 가상환경
**모듈**은 함수와 변수를 모아 둔 파이썬 파일이며 import로 불러옵니다. 외부 라이브러리는 **pip**로 설치합니다. 프로젝트마다 라이브러리 버전이 충돌하지 않도록 **가상환경**을 만들어 사용하는 것이 좋습니다.
