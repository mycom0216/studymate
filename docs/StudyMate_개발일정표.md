## 3. 위험과 일정 대응

| 위험 | 영향 | 대응 |
|---|---|---|
| Claude·ChatGPT API 키를 구하지 못함 | 실호출 검증 불가(요청 형식 테스트만 있음) | 12/05까지 키 확보 시도. 못 구하면 로컬 Ollama 결과만 보고하고 "미검증"으로 명시 |

| 카카오 연동에 공개 주소(터널·배포)가 필요 | 실연동 지연 | 12/16까지 임시 터널로 시도, 안 되면 자동 테스트 결과만 제시하고 미검증으로 명시 |
