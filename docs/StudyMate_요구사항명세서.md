## 3. 인터페이스 명세(API)

공통: JSON(UTF-8), `cache-control: no-store`. 학습자 식별은 `learnerId`(본문 또는 쿼리).

| 메서드·경로 | 설명 | 주요 입력 | 응답 |
|---|---|---|---|
| GET /api/status | 자료·LLM 상태 | – | chunks, units, retrieval(BM25 또는 hybrid), llm, llmProvider, llmError |
| GET /api/units | 단원 목록 | – | [{unit, title, user, chunks}] |
| GET /api/kb | 전체 항목(원문 포함) | – | [{id, title, unit, unitTitle, text, user}] |
| GET /api/kb/search?q= | 검색 확인용(200자까지) | q | confidence, hits[{id, title, unitTitle, score}] |
| POST /api/learners | 학습자 등록·이름 갱신 | learnerId, name | id, name |
| POST /api/chat | 질문 | learnerId, name?, question, level(normal·easy) | id, answer, generator, confidence, sources[], note, piiMasked[], related[], latencyMs / 400·413·429 |
| POST /api/chat/:id/feedback | 도움됨 표시 | learnerId, helpful | ok / 400·404 |
| POST /api/quiz | 퀴즈 출제 | learnerId, unit 또는 mode=review, count(1~10), ai | items[{id, qtype, prompt, options, unit, unitTitle, generator}] / 400·404·422 |
| POST /api/quiz/:id/answer | 채점 | learnerId, answer | correct, correctAnswer, explanation, source, box, nextReviewDays / 400·404·409 |
| GET /api/progress?learnerId | 학습현황 | learnerId | learner, totals, units, weak, due, recent |
| GET /api/recommend?learnerId | 오늘의 학습 추천 | learnerId | plan[], progress |
| POST /api/materials | 자료 추가 | title, text | unit, units / 400 |
| DELETE /api/materials/:unit | 내 자료 삭제 | – | ok / 404 |
| GET /api/stats | 운영 지표 | – | learners, questions, answeredRate, llmAnswers, extractiveAnswers, avgLatencyMs, helpfulRate, topUnits, quiz, quizByUnit, hardest |
| POST /kakao/skill?token= | 카카오 스킬 서버 | userRequest.utterance, userRequest.user.id | version 2.0, template.outputs·quickReplies (항상 200, 단 401·405 제외) |

오류 코드: 400 입력 오류 · 401 카카오 토큰 불일치 · 403 경로 이탈 · 404 대상 없음(남의 것 포함) · 405 카카오 POST 외 · 409 이미 제출 · 413 본문 과다 · 422 출제 불가 · 429 질문 간격 · 500 일반 문구.

## 4. 데이터 요구사항

SQLite 테이블 5개(learners, qa_log, quiz_items, attempts, mastery)와 파일 저장소(`knowledge/*.md`, `data/materials/*.md`, 선택적 `data/embeddings.json`)를 쓴다. 스키마에는 FOREIGN KEY·CHECK 제약이 **없고** 무결성(소유자 확인, 1회 채점)은 코드가 지킨다. 「데이터정의서」 참조.
