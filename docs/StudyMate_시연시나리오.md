# StudyMate 최종 발표 시연 시나리오 (5분)

발표자: 반재영 · 발표일 2026-12-30 · 시연 방식: 라이브 시연, 실패 시 시연 영상으로 대체

## 0. 발표 전 준비 체크리스트 (발표 30분 전)

| # | 확인 | 방법 |
|---|---|---|
| 1 | Node.js 24 이상 | `node -v` |
| 2 | 시연 데이터 넣기 | `node tools/seed-demo.mjs` (LLM 없이 실행, 같은 결과 재현) |
| 3 | 서버 실행 | `npm start` → <http://127.0.0.1:5300/?learner=demo-learner-01> |
| 4 | LLM 연결 상태 | 화면 상태 표시 확인. Ollama 사용 시 `ollama run kanana2:3b`로 미리 한 번 호출해 모델을 메모리에 올려 둠(첫 응답 지연 방지) |
| 5 | 인터넷 없는 상황 대비 | 키 없이도 동작하므로 Ollama 또는 추출형 답변으로 진행 가능 |
| 6 | 자료함에 붙여 넣을 노트 | 아래 "시연 6번 노트"를 메모장에 미리 복사해 둠 |
| 7 | 화면 | 브라우저 확대 125%, 알림 끄기, 탭은 StudyMate만 |
| 8 | 백업 | 시연 영상 파일과 화면 캡처(`docs/images/ui-*.jpg`)를 PPT 맨 뒤에 넣어 둠 |

주의: 평가 수치(검색 100%, 거절 85% 등)는 직접 만든 질문 세트 기준이므로 발표에서 "내 자료 기준"이라고 함께 말합니다.

## 1. 시간 배분

| 구간 | 시간 | 보여줄 것 |
|---|---|---|
| 1 | 0:00~1:30 | 학습 챗봇(RAG): 근거 표시, 모드 전환 |
| 2 | 1:30~2:15 | 환각 방지: 범위 밖 질문 거절 |
| 3 | 2:15~3:15 | 퀴즈 풀이와 채점 |
| 4 | 3:15~4:00 | 내 학습현황과 약점 복습 추천 |
| 5 | 4:00~4:40 | 자료함: 새 노트 추가 후 바로 질문 |
| 6 | 4:40~5:00 | 운영 지표와 마무리 |

## 2. 장면별 대본

### 장면 1. 학습 챗봇 (0:00~1:30)
**동작**
1. 학습 챗봇 탭에서 `과대적합이 뭐야?` 입력
2. 답변 아래 근거 칩을 클릭해 원문 항목 열기
3. 신뢰도 표시를 가리킴
4. "쉽게" 모드를 선택해 같은 질문을 다시 입력

**대본**
"StudyMate는 제 학습 자료를 근거로만 답하는 RAG 챗봇입니다. 질문하면 자료에서 관련 항목을 찾아 답하고, 어느 항목을 근거로 썼는지 바로 보여 줍니다. 칩을 누르면 원문이 열리니까 답이 맞는지 직접 확인할 수 있습니다. 같은 질문을 '쉽게' 모드로 다시 하면 설명 수준만 바뀝니다."

**확인 포인트**: 근거 칩에 과대적합 항목이 있는가, 신뢰도가 표시되는가.

### 장면 2. 환각 방지 (1:30~2:15)
**동작**: `양자컴퓨터 원리 알려줘` 입력 → 근거 없음 안내 확인

**대본**
"자료에 없는 질문을 하면 그럴듯하게 지어내는 게 챗봇의 가장 큰 문제입니다. 그래서 검색 신뢰도가 기준보다 낮으면 답하지 않고, LLM이 답해도 숫자와 인용이 자료와 맞는지 한 번 더 검사합니다. 제 평가 세트에서는 범위 밖 질문 20개 중 17개를 거절했고, 3개는 관련 없는 원문이 나갔습니다. 이건 아직 해결하지 못한 한계입니다."

**주의**: 시연 중 거절 대신 원문이 나오면(알려진 한계) 당황하지 말고 "바로 이 경우가 보고서에 적은 한계"라고 설명합니다.

### 장면 3. 퀴즈 (2:15~3:15)
**동작**
1. 퀴즈 탭에서 단원 `머신러닝`, 5문항 선택
2. 객관식 1개, 빈칸 1개, O/X 1개를 풀고(나머지는 빠르게 선택) 제출
3. 틀린 문제의 해설과 "다음 복습 시점" 확인

**대본**
"자료에서 객관식, 빈칸, O/X 문제를 자동으로 만듭니다. 정답은 문제 본문에 노출되지 않도록 자동 검사를 거쳤고, 132문제 전체에서 노출·보기 누락이 0건이었습니다. 다만 이 검사는 구조만 보고, 문제가 교육적으로 좋은지는 사람이 평가하지 않았습니다. 채점하면 해설이 나오고, 틀린 문제는 라이트너 방식으로 복습 시점이 잡힙니다."

### 장면 4. 내 학습현황 (3:15~4:00)
**동작**: 내 학습현황 탭 → 단원별 정답률, 약점 개념, 오늘의 학습 추천 → `약점 복습 퀴즈` 클릭

**대본**
"풀이 기록이 쌓이면 단원별 정답률과 약한 개념이 나옵니다. 이 화면은 시연용 데이터로 채운 것이라 실제 학습 효과를 측정한 결과는 아닙니다. 약점 복습 퀴즈를 누르면 틀린 개념 위주로 문제가 나옵니다."

**확인 포인트**: 시연 데이터 기준으로 머신러닝 정답률이 가장 낮게 나옵니다(데모 학습자 설정값 0.35).

### 장면 5. 자료함 (4:00~4:40)
**동작**: 자료함 탭에서 아래 노트를 붙여 저장 → 챗봇에서 `포모도로 기법이 뭐야?` 질문 → 근거에 내 노트가 뜨는지 확인

**시연용 노트 (복사해서 사용)**
```
# 포모도로 기법
포모도로 기법은 25분 집중해서 공부하고 5분 쉬는 것을 한 세트로 반복하는 시간 관리 방법이다. 네 세트를 마치면 15~30분 길게 쉰다. 짧은 단위로 나누어 집중력 저하를 줄이는 것이 목적이다.
```
**대본**
"내 노트를 붙여 넣으면 재시작 없이 바로 검색과 퀴즈에 반영됩니다. 방금 넣은 포모도로 노트가 근거로 나오는 걸 볼 수 있습니다."

**확인함**: "포모도로"와 "간격 반복"은 기본 자료 6개 단원에 없는 주제라 근거가 내 노트로만 나옵니다("교차검증"은 `ml.md`에 이미 있어 쓰지 않음). 리허설에서 실제 근거가 노트로 뜨는지 한 번 확인하세요.

### 장면 6. 운영 지표와 마무리 (4:40~5:00)
**동작**: 운영 지표 탭에서 질문 수, 근거 있는 답변 비율, 응답 시간 확인

**대본**
"운영 지표에서 근거 있는 답변 비율과 응답 시간을 볼 수 있습니다. 정리하면, 자료에 근거해 답하고, 모르면 모른다고 하고, 풀이 기록으로 약점을 짚어 주는 학습 도우미입니다."

## 3. 장애 대응

| 상황 | 대응 |
|---|---|
| LLM 응답이 5초 넘게 걸림 | "지금 로컬 모델이 답을 만드는 중입니다"라고 설명하며 대기. 10초 넘으면 `.env`에서 `LLM_PROVIDER=off`로 재시작하면 추출형 답변으로 즉시 응답 |
| 서버가 안 뜸 | 포트 5300 사용 중 여부 확인(`PORT=5301 npm start`). 안 되면 시연 영상으로 전환 |
| 화면이 비어 있음 | `?learner=demo-learner-01` 주소 확인, `node tools/seed-demo.mjs` 재실행 |
| 범위 밖 질문이 거절되지 않음 | 알려진 한계(범위 밖 20개 중 3개)로 설명 |
| 노트 추가 후 검색 안 됨 | 새로고침 후 재질문. 안 되면 영상으로 대체 |

## 4. 예상 질의응답

| 질문 | 답변 요지 |
|---|---|
| 왜 RAG를 썼나? | 학습 자료에 근거한 답만 필요하고, 근거를 보여 줘서 확인 가능해야 하므로. 모델이 자료 밖 내용을 지어내는 문제를 줄이려고 |
| 정확도는 얼마인가? | 직접 만든 질문 세트 기준 hit@1 100%(일반 60), 어려운 질문 83.3%(12). 임계값을 같은 세트로 골라 낙관적이며 실제 학습자 질문에서는 낮아질 수 있음 |
| 환각은 어떻게 막나? | 신뢰도 임계값 → LLM "근거 부족" 응답 → 숫자·인용·자료 일치도 검사 → 실패 시 원문 발췌. 의미가 반대인 답은 못 거름 |
| Claude/ChatGPT도 되나? | 어댑터는 구현했으나 이 개발 환경에는 키가 없어 가짜 서버로만 테스트함. 실제 호출은 검증하지 못함 |
| 왜 임베딩 검색은 안 썼나? | 선택 기능으로 구현했으나 이 PC에서 임베딩 모델이 비정상 종료되어 검증하지 못함. 기본은 BM25 |
| 실제 학습 효과가 있나? | 측정하지 않음. 화면의 기록은 시연용 데이터 |
| 개인정보는? | 질문을 마스킹(전화·이메일·카드·주민번호)하지만 그 밖의 정보는 못 거름. 외부 LLM 사용 시 자료함에 비공개 자료를 올리지 말 것. 로컬 Ollama는 외부 전송 없음 |
| 로그인은? | 없음. 브라우저 임의 ID로 학습자를 구분하는 교육용 데모 |
| 향후 계획은? | 임베딩 검색 검증, 문장 단위 근거 검증, PDF 업로드, 동의어 채점, 로그인 |

## 5. 시연 영상 촬영 가이드 (대체용)

- 해상도 1920×1080, 길이 4~5분, 위 장면 1~6 순서 그대로 녹화 (Windows `Win+Alt+R` 또는 OBS)
- 마이크는 별도 녹음하지 않고 자막이나 발표 중 설명으로 대체해도 됨
- 장면마다 한 번에 끝내고, 응답 대기 시간이 길면 편집에서 자르되 "편집됨" 자막을 넣어 응답 시간을 속이지 않음
- 파일명 `StudyMate_시연영상.mp4`로 `docs/`에 두고 제출물에 포함
